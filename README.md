# SIH Results Monitor (deployment copy)

Sanitized deployment bundle generated from the private development workspace. It excludes recipient addresses, OAuth files, SQLite data, historical result fixtures, test data, and development notes. The workflow runs on free standard `ubuntu-latest` hosted runners every 15 minutes. While Drive sync is disabled, scheduled runs report that monitoring is not enabled; manual runs perform a local, non-persistent monitoring cycle. Once Drive OAuth and folder secrets are configured and `SIH_DRIVE_SYNC_ENABLED` is set to `true`, each schedule restores the latest SQLite snapshot, processes results and retries the outbox, then uploads a new immutable snapshot. Set up the `sih-monitor` Environment to allow only the trusted default branch. Put `DRIVE_OAUTH_TOKEN_JSON`, `DRIVE_FOLDER_ID`, `SIH_SENDER_EMAIL`, and `SIH_RECIPIENTS_YAML` in Environment Secrets only. The workflow hard-codes `DRY_RUN=true`, `EMAIL_TRANSPORT=mock`, and `ENABLE_REAL_EMAIL=false`; no Gmail token is used and live delivery is unavailable.
